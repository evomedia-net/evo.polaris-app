Changelog
=========

Notable changes to evo.polaris-app, newest first. Each entry links the pull request that made it.

Versions have five parts, v{major}.{rc}.{beta}.{alpha}.{build}, and the build number
advances once per release. New changes go under Unreleased in the same pull request,
and the release moves them under its version.

Unreleased
----------

Added
~~~~~

- e2e: Appium end-to-end tests of the Android app on an emulator, in CI on every pull request: Android's location-permission dialog, the speech shim, the system bars in full screen, turning the phone, and WCAG checks in the accessibility tree TalkBack reads (#5 (https://github.com/evomedia-net/evo.polaris-app/pull/5))
- store: app icons, screenshots and listing text, store version numbers, Android release signing and a TestFlight upload (#3 (https://github.com/evomedia-net/evo.polaris-app/pull/3))
- bundle the released polaris in a Capacitor shell for Google Play and the App Store (#1 (https://github.com/evomedia-net/evo.polaris-app/pull/1))

Changed
~~~~~~~

- e2e: e2e/package.json lists Appium's install script, pinned to its version. npm 12, which the workstation now runs, runs a dependency's install script only if allowScripts in package.json lists it. The script installs extra drivers only when an install asks for them with --drivers, and the UiAutomator2 driver is already a dependency here, so the approval keeps installs as they were under npm 11 (#6 (https://github.com/evomedia-net/evo.polaris-app/pull/6))
